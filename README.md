## ✨ 核心工程特性

本项目已升级为模块化架构（[`config/`](./config/) 配置中心 + [`core/`](./core/) 核心引擎），通过 GitHub Actions 每日定时自动化运行 [`update_sources.py`](./update_sources.py)，围绕**“高可用、真播放测速、自进化去死链、多线分级与电视端体验优化”**构建完整的自动化数据管线：

1. **多源聚合、主备容错与本地快照兜底**
   * 整合多个主流公开单仓、多仓中心与 CMS 接口，支持中文国际化域名（IDN）自动转 Punycode，内置 `okhttp` 与标准浏览器双请求头自适应切换及非标 JSON 宽容解析。
   * 对主力单仓配置主备地址轮询，并在抓取成功时自动落盘历史快照至 [`cache/`](./cache/) 目录；一旦某次上游主备全挂，自动无缝回退加载本地缓存快照，结合 [`source_registry.json`](./source_registry.json) 管理健康度与失败计数，同时自动洗白失效第三方代理前缀。
2. **自进化源仓治理（15 次 + 15 天长期死链物理清除）**
   * 自动发现并验证上游仓库的新增直播与点播接口；自动发现的野源连续失败 `3` 次即淘汰。
   * 静态种子源在连续失败 `4` 次后自动进入休眠降频探测；若同时满足**连续失败 `≥ 15` 次且首次连续失败距今满 `15` 天**，系统将自动执行物理删除并写入 `purged_seeds` 防回流黑名单，彻底避免僵尸死链占用配置体积。
3. **外部 JAR 与规则文件存活预检 + 搜剧净化**
   * 跨仓聚合时自动解析并补全爬虫站点对应的 `jar` 依赖与 `ext` 规则路径，合并前并发预检外部 JAR（镜像缓存至 [`jars/`](./jars/)）与 `.js`/`.json` 规则链接存活状态，剔除 404 或超时死链依赖站。
   * 自动过滤广告、购物、公告、占位及不可搜索的纯展示干扰站，并对同源 `ext` 域名做归一化去重合并，提升电视端聚合搜索纯净度。
4. **三线分级点播、TS 分片真测速与智能首页排位**
   * **高速精简版 (`tvbox_lite.json`)**：对 Top 20 CMS 接口执行**真实 M3U8/TS 视频分片下载测速**，自动过滤成人/敏感站点；将分片通畅的高速直连站智能置顶为首页第 1 站（打开即看），内置标准分类 `ext` 的增强版豆瓣热播榜排在第 2 位，默认将**硬解码（MediaCodec / HEVC）**置于解码器首位，兼顾启动速度与 4K 流畅度。
   * **全量聚合版 (`tvbox.json`)**：汇集测速通过的 CMS 接口、网盘爬虫及经过依赖校验的爬虫站点，适合作为总库备用。
   * **纯网盘聚合专版 (`tvbox_pan.json`)**：专注聚合网盘与盘搜站点，对头部直连网盘站开启 `quickSearch` 快搜并发，其余长尾网盘站关闭快搜并发以减轻电视端并发压力，并清理明显失效的占位 Token/Cookie 参数。
   * **双应急绝对路径单仓 (`tvbox_cf_abs.json` / `tvbox_proxy_abs.json`)**：自动基于本次测速最快的 Cloudflare 域名与最快前置代理生成完整绝对路径配置，应对个别客户端版本（如部分 NewBox / 原版分支）对相对路径解析的兼容问题。
5. **频道名归一化直播与 EPG 节目单**
   * 抓取 M3U/TXT 直播流并进行真实媒体流特征校验（过滤 HTML 假活页面），对频道名称执行标准化归一化（如统一 `CCTV-1`、`CCTV1`、`CCTV-1综合` 等命名），结合画质/IPv6 加分与延迟排序，同频道最多保留最优多线路并自动注入 EPG 节目预告与台标接口。
6. **多域名冗备与双层前置代理池**
   * 测速多组自定义域名与 GitHub 开源前置加速代理（同时校验 JSON 与 `custom_spider.jar` 完整性），维护 [`active_proxies.json`](./active_proxies.json)（全量前 10）与 [`active_proxies_lite.json`](./active_proxies_lite.json)（实测最快前 3），并按“CF 精简 -> CF 网盘 -> CF 全量 -> 代理线 -> 双应急绝对路径”顺位组装为多仓总入口 [`dc.json`](./dc.json)。

## 📂 仓库目录与核心产物说明

| 路径 / 文件名 | 类型 | 用途与说明 |
| :--- | :--- | :--- |
| **`config/`** | 规则与配置中心 | 包含 [`settings.json`](./config/settings.json)（全局阈值/硬解码参数）、[`seeds.json`](./config/seeds.json)（种子库）与 [`rules.json`](./config/rules.json)（过滤清洗规则） |
| **`core/`** | 核心处理引擎 | 包含 [`builder.py`](./core/builder.py)（分片测速与多版本构建）、[`live.py`](./core/live.py)（直播聚合）、[`vod.py`](./core/vod.py)（点播发现）与 [`utils.py`](./core/utils.py)（通用工具） |
| **`dc.json`** | 多仓聚合总入口 | 汇总高可用域名、精简/网盘/全量代理线及 CF/代理双绝对路径应急入口 |
| **`tvbox_lite.json`** | 高速精简版配置 | 经 TS 分片真测速、智能第 1 站置顶、过滤成人站且硬解码优先的电视日常首选配置 |
| **`tvbox.json`** | 全量点播与直播配置 | 包含全量去重测速与依赖校验后的点播站点、标准化解析接口（`parses`）及直播引用 |
| **`tvbox_pan.json`** | 纯网盘聚合专版 | 专注网盘与盘搜站点，头部网盘站开启快搜并发，优化网盘搜剧体验 |
| **`tvbox_cf_abs.json`** | CF 应急绝对路径单仓 | `spider` 与 `lives` 指向最快可用 Cloudflare 域名的绝对路径，用于相对路径兼容应急 |
| **`tvbox_proxy_abs.json`** | 代理应急绝对路径单仓 | `spider` 与 `lives` 指向最快可用前置代理的绝对路径，用于相对路径兼容应急 |
| **`tvbox_live.txt`** | 精选电视直播列表 | 经流媒体校验、频道名归一化与画质/延迟综合排序的直播源 |
| **`custom_spider.jar`** | 基础爬虫依赖包 | 同步自上游开源仓库的基础 Spider JAR，支撑本地与同目录站点运行 |
| **`jars/`** | 第三方爬虫本地镜像 | 自动验证并镜像缓存第三方单仓的活跃爬虫 JAR 包 |
| **`cache/`** | 主力源历史快照目录 | 保存主力单仓最近一次成功抓取的结构化快照，上游临时抽风时自动兜底 |
| **`source_registry.json`** | 上游源健康度注册表 | 记录直播源、点播配置源及 CMS 接口的来源标记、延迟、连续失败计数与首次失败时间 |
| **`active_proxies.json`** | 全量前置代理状态池 | 记录经过端到端测速验证的前 10 个 GitHub 文件加速代理及健康度评分 |
| **`active_proxies_lite.json`** | 精简高速代理池 | 仅保留实测延迟最低的前 3 个可用加速代理节点 |

## ⚙️ 自动化运行架构与客户端使用说明

* **调度工作流**：[`.github/workflows/daily_update.yml`](./.github/workflows/daily_update.yml)
* **执行频率与时区**：每日定时自动执行（UTC `20:17`，对应**中国大陆北京时间次日 `04:17`**），所有配置文件内嵌的 `updated_at` 与缓存版本标签均统一采用**北京时间 (`UTC+8`)**；亦支持在 **Actions** 面板手动触发 `workflow_dispatch`。
* **健康度简报**：每次工作流运行结束后，脚本会自动在对应 Run 的 **Summary** 页面生成《TVBox 自动更新健康简报》，展示各版本站点**较上期增减对比**、外部依赖存活校验结果、主力源贡献明细及前排低延迟代理节点。
* **客户端刷新指引（FONGMI / OK影视 / 影视仓 / NewBox）**：
  * **日常自动更新**：FONGMI 与 OK影视在完全退出后重新启动（冷启动）时会自动异步拉取最新单仓与跨天直播台表。
  * **立即强制刷新**：在任意客户端中进入 **设置 -> 配置地址 -> 直接点击“确定”**，即可强制清空本地配置缓存并校验 `;md5;` 重新下载最新配置文件与 `custom_spider.jar`。
